## 👁️ ReSeen — Never Miss What Was Said.

**ReSeen** is an offline-first deleted chat and media recovery engine for WhatsApp, Messenger, Telegram, and Instagram.

* 🛡️ **Zero-Leak Guarantee:** 100% on-device capture without any cloud uploads.
* 📸 **Universal Media Hub:** Recovers deleted photos, voice notes, stickers, and images.
* 🧠 **Cognitive Sentinel:** AI-powered spam detection and behavioral conversation forensics.
* 🎨 **12 Heritage Bengali Themes:** Handcrafted Cyberpunk & Heritage themes.
* 🔒 **Biometric Vault:** Pattern, PIN, Fingerprint, and Face ID lock.
